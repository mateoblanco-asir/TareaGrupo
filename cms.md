# ¿Qué es un CMS?

Un sistema de gestión de contenidos  (CMS) es un software que ayuda a los usuarios a
crear, gestionar, almacenar y modificar sus contenidos digitales de un sitio web sin
necesidad de desarrollar manualmente cada página desde cero.

## ¿Cómo funciona un CMS?
Un CMS funciona en dos partes fundamentales divididas 

-Una donde el usuario atraves de una interfaz gráfica (CMA) puede crear, administrar , editar y subir su contenido

-Y un motor interno (CDA) que toma el contenido, lo procesa y lo muestra


## Tipos de CMS y Ejemplos

### Según su Arquitectura
1.   **CMS Tradicional:** Contenido y diseño van unidos en una sola plataforma. Fácil de usar con editores visuales. | Ej: WordPress, Joomla.
2.  **CMS Headless:** Separa el contenido del diseño. | El contenido se gestiona de forma centralizada y se envía a webs o apps mediante APIs. | Ej: Strapi, Contentful.
3.  **CMS Híbrido:** Combina ambos mundos. Permite diseñar páginas visualmente y, a la vez, distribuir contenido estructurado por API. | Ej: Adobe Experience Manager, Magnolia.

### Según su Propósito
1.  **Web (WCM):** Webs generales y periódicos. | Ej: WordPress, Joomla, Ghost, Blogger.
2.  **Educativos (LMS):** Academias y cursos online. | Ej: Moodle, Canvas LMS, Chamilo.
3.  **Empresariales (ECM/DXP):** Grandes empresas y experiencias corporativas. | Ej: Liferay, TYPO3, Sitecore.*
4.  **Activos Digitales (DAM):** Almacén central de imágenes, vídeos y archivos. | Ej: Bynder.
5.  **Comercio Electrónico:** Tiendas online con pasarelas de pago y carritos. | Ej: Shopify, PrestaShop, Magento.
6.  **Wikis:** Bases de conocimiento colaborativas. |  Ej: MediaWiki, TikiWiki.
7.  **Foros:** Comunidades de discusión por hilos. |  Ej: phpBB, vBulletin.





## Comparación entre un CMS dinámico y un generador de sitios estáticos

| Aspecto | CMS dinámico | Generador estático |
| ---- | ---- | ---- |
| **Forma de crear contenidos** | Editor visual intuitivo sin codigo | Archivos de texto plano en Markdown. |
| **Base de datos** | Si | No, utiliza archivos locales o Git |
| **Generación del HTML** | En tiempo de ejecución | En tiempo de compilación |
| **Servidor necesario** | Servidor dinámico. | Servidor web básico |
| **Panel de administración** | Integrado en la web | Inexistente |
| **Conocimientos técnicos** | Bajos | Medios/Altos |
| **Seguridad** | Menor | Avanzado |
| **Rendimiento** | Variable | Ultra rápido |
| **Actualización del contenido** | Inmediata al guardar en el panel. | Requiere recompilar |
| **Publicación** | Proveedores de hosting tradicionales. | Plataformas de despliegue automatizado |
| **Ejemplos** | WordPress, Shopify, Joomla. | Jekyll, Hugo, Astro |
